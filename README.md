# Top Spots!
## Find and Explore Activities in San Diego! 📃
Find and read up on different fun activities to do in San Diego, and see the locations of these places!

## Installation Instructions 🚀
1. git clone https://github.com/dfranco01/React-Top-Spots.git
2. Terminal Command: cd React-Top-Spots
3. install dependencies: npm install
4. Run Development Server: npm run dev
5. Open http://localhost:5173/ in your browser 

## Technologies 🛠️
HTML, CSS, React.js
